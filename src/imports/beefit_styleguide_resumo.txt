                         Resumo para Desenvolvimento LLM

IDENTIDADE
-----------
Nome: BeeFit (B + "ee" como abelha + Fit)
Tipo: App mobile de rede social de fitness/treino
Tom de voz: Motivacional, direto, energético
Estilo visual: Dark mode com acentos vibrantes
Temática: Colmeia / Abelhas — hexágonos como elemento visual recorrente

================================================================================
1. PALETA DE CORES
================================================================================

------------------------------

Yellow Light          #FFE44D  → Hover states da primária
Yellow Dark           #E6C200  → Pressed/active states da primária

Gray 400              #A3A3A3  → Labels, metadados
Gray 700              #404040  → Bordas de input inativo

1.2 CORES SEMÂNTICAS (Ações de Treino)
---------------------------------------

Green Light           #4ADE80  → Hover do verde

1.3 CORES DE RARIDADE (PR Cards)
---------------------------------
Common (Comum)        #737373  → PR básico, pesos mais leves
Rare (Rara)           #3B82F6  → PR intermediário
Epic (Épica)          #A855F7  → PR avançado
Legendary (Lendária)  #FFD700  → PR máximo, pesos mais pesados

REGRA DE USO DAS CORES SEMÂNTICAS:
- Verde SEMPRE = ação de conclusão/sucesso (finalizar treino, marcar feito)
- Azul SEMPRE = ação de início/progresso (iniciar treino, play, continuar)
- Vermelho SEMPRE = ação destrutiva/cancelamento (cancelar, sair, excluir)
- Amarelo SEMPRE = brand/CTA principal (entrar, cadastrar, navegação ativa)
- Roxo = raridade épica (PR cards)
- Cinza = raridade comum (PR cards)

2. TIPOGRAFIA
================================================================================

6. ELEMENTOS HEXAGONAIS (Tema Colmeia)
================================================================================

O hexágono é o elemento visual recorrente da marca BeeFit, representando:
- Colmeia / abelhas ("Bee" no nome)
- Eficiência estrutural (hexágonos são formas fortes)
- Organização e disciplina (padrão de colmeia)

APLICAÇÕES DOS HEXÁGONOS:

6.1 Background Pattern
-----------------------
- Padrão de hexágonos sutis (opacity 0.03) como background de todas as telas
- Cor do stroke: #FFD700 (amarelo)
- Tamanho: 56px x 100px (desktop), 40px x 70px (mobile)
- stroke-width: 1px (desktop), 0.8px (mobile)

6.2 Logo do Aplicativo
--------------------------
- Arquivo chamado logobeefit

6.3 Elementos Decorativos
--------------------------
- Hexágonos nos cantos superiores dos cards (opacity 0.05-0.10)
- Hexágonos flutuantes no header do style guide (opacity 0.10-0.20)
- Hexágonos pequenos nos avatares (canto superior direito, opacity 0.6)
- Hexágonos nos dividers de seção (opacity 1.0, amarelo)

6.4 Ícones de Seção
--------------------
- Cada título de seção tem um hexágono amarelo como ícone à esquerda
- Tamanho: 36px x 42px

6.5 Labels de Tipo
-------------------
- Labels de tipografia têm um hexágono amarelo como bullet
- Tamanho: 8px x 9px

6.6 Muscle Tags
----------------
- Tags de grupos musculares têm um hexágono como dot indicator
- Cor do hexágono: mesma cor do texto da tag

6.7 Badges / Chips
-------------------
- Chips de músculos ativos têm um hexágono preto como ícone
- Hexágono posicionado à esquerda do texto

6.8 PR Cards
-------------
- Hexágono decorativo no canto superior direito (opacity 0.06)
- Tamanho: 100px x 115px

CLIP-PATH DO HEXÁGONO:
  polygon(50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25%)

9. CARDS DE RECORDE (PR — Personal Record)
================================================================================

Cartas que representam o peso recorde alcançado em cada exercício.
Funcionam como "conquistas" ou "troféus" do usuário.

9.1 Sistema de Raridade
------------------------
A raridade é determinada pelo peso levantado em relação ao peso corporal
ou por milestones predefinidos:

  Comum (Common)     → PRs básicos, pesos iniciais
  Rara (Rare)        → PRs intermediários
  Épica (Epic)       → PRs avançados
  Lendária (Legendary) → PRs máximos, recordes pessoais absolutos

12. REGRAS GERAIS
================================================================================

  2. O amarelo (#FFD700) é a cor de marca. Não usá-la para status/semântica.
  3. Verde = concluído/sucesso. Azul = iniciar/em progresso. Vermelho = cancelar/erro.
  4. Todos os botões principais devem ser pill-shaped (radius full).
  5. Cards devem ter hover com elevação e borda amarela.
  6. Inputs sempre com borda escura, foco amarelo.
  7. Texto principal sempre branco (#FFFFFF). Nunca use cinza claro para body.
  8. Use Montserrat SOMENTE para títulos, botões e números.
  9. Use Inter SOMENTE para body text, labels e captions.
  10. Mantenha consistência: mesmo padrão de spacing em todas as telas.
  11. HEXÁGONOS são obrigatórios em: logo, background pattern, canto dos cards,
      avatares, ícones de seção, dividers, muscle chips.
  12. O boneco muscular deve mostrar grupos ativos em amarelo com glow.
  13. Cada tela deve ter o padrão hexagonal sutil no background.
  14. PR Cards devem ter shine animation, especialmente os lendários.
  15. Raridade dos PRs deve ser claramente identificável pela cor da borda e do peso.
  16. Dois bonecos são necessários: frontal (7 grupos) e dorsal (10 grupos).
  17. Proporções humanas devem ser respeitadas (cabeça ~1/7.5 da altura total).
  18. Cada PR card DEVE ter um ícone SVG customizado do grupo muscular trabalhado.
  19. Cada PR card DEVE ter uma miniatura do boneco com músculos atingidos destacados.
  20. Ícones de grupo muscular devem ser consistentes em toda a aplicação.
